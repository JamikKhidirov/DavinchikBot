# 💕 Davinchik Bot — Telegram Dating Bot

**Davinchik Bot** — это мощный Telegram бот для знакомств, написанный на Python с использованием aiogram 3 и SQLAlchemy 2.0 (async).
Реализует полный цикл знакомств: анкеты → лайки → взаимные симпатии → встроенный чат + подарки.

---

## 🚀 Возможности

### 👤 Пользовательские
| Функция | Описание |
|---|---|
| **📝 Регистрация** | Создание анкеты: имя, возраст, пол, город, bio, интересы (15 видов), до 3 фото/видео |
| **🔍 Поиск анкет** | Tinder-style: одна анкета за раз, ❤️ / ⭐ / 👎, фильтр по полу |
| **⭐ Суперлайк** | Анонимный суперлайк + короткое сообщение, получатель не видит кто |
| **💕 Взаимные симпатии** | Взаимный лайк → Match с уведомлением обоим + сообщение суперлайка |
| **💬 Встроенный чат** | Переписка между совпадениями внутри бота + ссылка на Telegram DM |
| **🏙 Поиск по городу** | Сначала анкеты из твоего города, если нет — из всех городов |
| **🗺 Поиск по геолокации** | Отправка геопозиции, поиск в радиусе (до 1000 км), сортировка по расстоянию |
| **🎯 Интересы/теги** | 15 интересов на выбор, сортировка по совпадению интересов |
| **📸 Верификация фото** | Админ подтверждает фото в ЛС → ✅ галочка на анкете |
| **📊 Статистика** | Просмотры (за неделю/месяц/всё время), лайки, совпадения |
| **🎯 Настройки поиска** | Возраст, пол, город, радиус, геопозиция |
| **🚫 Блокировка** | Блок/разблокировка пользователей |
| **💬 Жалобы** | Отправка жалобы администраторам |
| **🕵️ Анонимные сообщения** | Анонимные сообщения с возможностью ответа (двусторонний анонимный чат) |
| **🎁 Подарки** | 6 видов подарков (🌹❤️🍫💍🎂🧸) через Telegram Stars |
| **🔗 Реферальная система** | Приведи друга → +15 лайков тебе, +10 другу + 7 дней Премиум + 🏆 значок обоим |
| **🔔 Уведомления** | Push при лайке, суперлайке, взаимной симпатии, подарке |
| **⭐ Премиум** | Безлимитные лайки, буст анкеты, кто лайкнул |
| **🗑 Удалить / 🔄 Создать заново** | Удаление анкеты с очисткой лайков/совпадений или пересоздание через /register |
| **🎁 Бонусы при старте** | При /start показывается реферальная ссылка и бонусы за друзей |

### 👑 Административные
| Функция | Описание |
|---|---|
| **📊 Статистика** | Пользователи, анкеты, лайки, мэтчи, жалобы |
| **📢 Реклама** | Создание/список/вкл-выкл/редактирование/удаление, трекинг показов и кликов, **отправка всем** |
| | Конструктор баннера: текст + фото + название кнопки + ссылка (сайт или бот) |
| **👥 Пользователи** | Список, бан/разбан, инфо, удаление анкеты |
| **🚫 Жалобы** | Просмотр, закрытие, бан с жалобы |
| **✅ Верификация** | Просмотр фото, подтверждение/отклонение |
| **📨 Рассылка** | Массовая рассылка сообщений (текст + фото) |
| **⭐ Баланс Stars** | Просмотр заработка, заявки на вывод |
| **🎁 Выдать премиум/буст/подарки/лайки** | Выдача любому пользователю по Telegram ID |
| **📈 Частота рекламы** | `/admin_ad_freq <число>` — настройка показа рекламы |
| **🔧 Команды** | `/admin_ban`, `/admin_unban`, `/admin_userinfo`, `/admin_deleteprofile`, `/admin_ad_freq` |

### 💳 Монетизация (Telegram Stars)
| Услуга | Цена |
|---|---|
| Премиум 1 месяц | 50 ⭐ |
| Премиум 3 месяца | 120 ⭐ |
| Премиум навсегда | 300 ⭐ |
| Буст анкеты (7 дней) | 30 ⭐ |
| Подарки (🌹❤️🍫💍🎂🧸) | 15–100 ⭐ |
| Рекламный баннер (30 дней) | 200 ⭐ |

### 🛡 Системные
- **Throttling middleware** — защита от флуда (0.5с)
- **Graceful shutdown** — корректное закрытие БД
- **Авто-деактивация** — скрытие анкет неактивных >30 дней
- **Лимит лайков** — 30/день для free, безлимит для premium
- **Авто-миграции** — новые колонки добавляются при старте без потери данных
- **Тестовая БД** — отдельная `test_database.sqlite3` для тестов
- **Логирование** — файл + stdout

## ⚙️ Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/JamikKhidirov/DavinchikBot.git
cd DavinchikBot
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Настроить `.env`
```env
BOT_TOKEN=1234567890:ABCdefGHIjklmNOPqrstUVwxyz
ADMIN_IDS=123456789,987654321
```

| Параметр | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather | **обязательно** |
| `ADMIN_IDS` | Telegram ID админов через запятую | `""` |
| `swipe_before_ad` | Через сколько свайпов показывать рекламу | `3` |
| `max_likes_per_day` | Лимит лайков для free-пользователей | `30` |
| `inactive_days_before_hide` | Дней до скрытия неактивных анкет | `30` |
| `REFERRER_BONUS_LIKES` | Бонусных лайков пригласившему | `15` |
| `REFERRED_BONUS_LIKES` | Бонусных лайков новому пользователю | `10` |
| `REFERRAL_PREMIUM_TRIAL_DAYS` | Дней премиум-триала за реферала | `7` |
| `premium_1m_stars` | Стоимость премиум 1 месяц | `50` |
| `premium_3m_stars` | Стоимость премиум 3 месяца | `120` |
| `premium_lifetime_stars` | Стоимость премиум навсегда | `300` |
| `boost_stars` | Стоимость буста на 7 дней | `30` |

### 4. Запустить
```bash
python -m app.main
```

При первом запуске:
- Создадутся таблицы БД
- Автоматически установятся команды бота, описание, название
- Неактивные анкеты (>30 дней) скроются
- Истекшие премиум/буст деактивируются
- Админы из `ADMIN_IDS` получат права

### Тестирование
```bash
pytest tests/ -v
# Использует отдельную test_database.sqlite3
```

## 🤖 Команды бота

### Пользовательские
| Команда | Описание |
|---|---|
| `/start` | Запуск / регистрация (поддерживает `ref_CODE`) |
| `/register` | Создание анкеты |
| `/menu` | Главное меню |

### Админские
| Команда | Описание |
|---|---|
| `/admin` | Админ-панель |
| `/admin_ban <id>` | Забанить пользователя |
| `/admin_unban <id>` | Разбанить |
| `/admin_userinfo <id>` | Инфо о пользователе |
| `/admin_deleteprofile <id>` | Удалить анкету |
| `/admin_ad_freq <N>` | Частота рекламы (свайпов) |
