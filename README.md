# 💕 Davinchik Bot — Telegram Dating Bot

**Davinchik Bot** — это мощный Telegram бот для знакомств, написанный на Python с использованием aiogram 3 и SQLAlchemy 2.0 (async).  
Реализует полный цикл знакомств: анкеты → лайки → взаимные симпатии → общение.

---

## 🚀 Возможности

### 👤 Пользовательские
| Функция | Описание |
|---|---|
| **📝 Регистрация** | Создание анкеты: имя, возраст, пол, город, bio, до 3 фото |
| **🔍 Поиск анкет** | Tinder-style: одна анкета за раз, ❤️ / 👎 |
| **💕 Взаимные симпатии** | Взаимный лайк → Match с уведомлением обоим |
| **🏙 Поиск по городу** | Сначала анкеты из твоего города, если нет — из всех городов |
| **📸 Верификация фото** | Админ подтверждает фото → ✅ галочка на анкете |
| **📊 Статистика** | Просмотры анкеты, полученные лайки, совпадения |
| **🎯 Настройки поиска** | Возраст, пол, город |
| **🚫 Блокировка** | Блок/разблокировка пользователей |
| **💬 Жалобы** | Отправка жалобы администраторам |
| **🔔 Уведомления** | Push при лайке и взаимной симпатии |
| **⭐ Премиум** | Безлимитные лайки и другие преимущества |

### 👑 Административные
| Функция | Описание |
|---|---|
| **📊 Статистика** | Пользователи, анкеты, лайки, мэтчи, жалобы |
| **📢 Реклама** | Создание/список/вкл-выкл, трекинг показов и кликов |
| **👥 Пользователи** | Список, бан/разбан |
| **🚫 Жалобы** | Просмотр, закрытие, бан с жалобы |
| **✅ Верификация** | Просмотр фото, подтверждение/отклонение |
| **📨 Рассылка** | Массовая рассылка сообщений (текст + фото) |

### 🛡 Системные
- **Throttling middleware** — защита от флуда (0.5с)
- **Graceful shutdown** — корректное закрытие БД
- **Авто-деактивация** — скрытие анкет неактивных >30 дней
- **Лимит лайков** — 30/день для free, безлимит для premium
- **Логирование** — файл + stdout

## ⚙️ Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/JamikKhidirov/DavinchikBot.git
cd DavinchikBot
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Настроить `.env`
```env
BOT_TOKEN=1234567890:ABCdefGHIjklmNOPqrstUVwxyz
ADMIN_IDS=123456789,987654321
DATABASE_URL=sqlite+aiosqlite:///./data/database.sqlite3
```

| Параметр | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_IDS` | Telegram ID админов через запятую |
| `DATABASE_URL` | Строка подключения к БД (по умолчанию SQLite) |
| `swipe_before_ad` | Через сколько свайпов показывать рекламу |
| `max_likes_per_day` | Лимит лайков для free-пользователей |
| `inactive_days_before_hide` | Через сколько дней скрывать неактивных |

### 4. Запустить
```bash
python -m app.main
```

При первом запуске:
- Создадутся таблицы БД
- Автоматически установятся команды бота, описание, название
- Неактивные анкеты (>30 дней) скроются
